عنوان پروژه: بدهی فنی 
هدف و کاربرد پروژه: در یک فروشگاه اینترنتی تیم تابع تخفیفی برای فروشگاه نوشته است و نسخه اولیه تمیز و ساده است اما در نسخه دوم بدهی شروع می شود، در نسخه سوم که یک سال بعد رخ داده است بدهی انباشت شده است
توضیح کوتاهی درباره نحوه اجرای برنامه: کدها داخل ویژوال استودیو اجرا میشوند و تخفبف هایی ک به مشتری ها داده میشود نشان داده میشوند اما محور اصلی پروژه بدهی فنی است که نشان میدهد کدها زیادتر میشوند و بدهی ایجاد میشود.
ابزار ها و کتابخانه های استفاده شده:تمام import ها از کتابخانه استاندارد پایتون هستند.
